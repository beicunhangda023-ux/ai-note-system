# どこで契約したか分からないサブスクを見つけて解約する｜App Store・Google Play・Webやキャリア決済の3パターン

## アプリを消したのに、請求が止まらない

カードの明細を見たら、毎月980円の請求がある。何のお金なのか、思い出せません。それらしいアプリはもう消したのに、翌月もまた同じ請求が来ている。「どこで解約すればいいのか」を調べても、出てくる説明はどれも自分の画面と違う。そんな状態で止まっていませんか？

## この記事が向いていない人

- どのサービスか、どこで契約したかが分かっている人（そのサービスのヘルプを見たほうが早いです）
- 請求に心当たりがまったくなく、カードの不正利用が疑われる人。先にカード会社へ連絡してください（書式3が使えます）
- 法人カードや、会社の経費で契約したサブスクを解約したい人

## 全体像：明細から始めて、4ステップで終わります

[ここに体験]

サブスク（毎月や毎年、自動でお金を払い続ける契約）は、アプリを消しても止まりません。契約は、アプリの中ではなく「どこでお金を払っているか」の側にあるんですよね。

なので、探す順番はアプリからではなく、お金の側からです。

| ステップ | やること | 時間の目安 |
|---|---|---|
| 1 | カードの明細を3か月分見て、毎月の請求を書き出す | 15分 |
| 2 | 明細の表示名から、どこで契約したかを見分ける | 10分 |
| 3 | 契約した場所ごとの画面で解約する | 1件5〜10分 |
| 4 | 解約できたかを確かめる | 5分＋翌月の明細 |

使うものは、次の3つです。

- クレジットカードの明細（カード会社のアプリかWebの会員ページ）
- 契約していそうなスマホ（家族のスマホも含む）
- スマホの料金の明細（キャリア決済を使っている場合）

「どこで契約したか」は、大きく分けて3通りしかありません。この3つのどれかが分かれば、解約の画面にたどり着けます。

## 有料部分に入っているもの

- 状況の分かれ方（App Store経由／Google Play経由／Webで直接・キャリア決済）と、それぞれの解約画面
- カードの明細から、毎月の請求を書き出す手順と記入表
- 明細の表示名から、契約した場所を見分ける早見表
- iPhoneの「設定」からサブスクリプションを解約する手順
- Google Playの「定期購入」を解約する手順
- Webで直接契約したもの・キャリア決済で払っているものを探して解約する手順
- 家族のスマホで契約されていた場合の確かめ方
- つまずきやすい箇所4つと、その対処
- そのまま使える書式3つ（サブスクの書き出し表／サービスへの問い合わせ文／カード会社への問い合わせ文）
- 解約できたかを確かめる方法

ーーー ここから有料 ーーー

## 状況の分かれ方：A・B・Cのどれかを見分ける

解約の画面は、どこを通してお金を払っているかで決まります。

| | 状況 | 解約する場所 |
|---|---|---|
| A | App Store（iPhone・iPad）を通して払っている | iPhoneの「設定」 |
| B | Google Play（Android）を通して払っている | 「Playストア」アプリ |
| C | サービスのWebサイトで直接払っている。またはスマホ料金と一緒に払っている（キャリア決済） | サービスのWebサイト、または携帯会社の会員ページ |

AとBは、アプリの中に「解約」ボタンがあっても、そこでは解約できないことがあります。払っている場所の画面で解約するのが確実なんです。

## ステップ1：カードの明細を3か月分見て、毎月の請求を書き出す

1. カード会社のアプリか、Webの会員ページにログインします。
2. 「ご利用明細」や「利用履歴」を開き、直近3か月分を表示してください。
3. 毎月同じ日ごろに、同じ金額が出ている行を探します。年払いのサブスクもあるので、1年分を見られるなら1年分見ます。
4. 見つけた行を、「書式1」の表に書き写します。

入力例です。

| 明細の表示名 | 金額 | 請求日 |
|---|---|---|
| APPLE.COM/BILL | 980円 | 毎月12日 |
| `GOOGLE *YouTube` | 1,280円 | 毎月3日 |
| NETFLIX.COM | 1,590円 | 毎月20日 |

スマホの料金と一緒に払っている人は、携帯会社の明細も同じように見ます。

## ステップ2：明細の表示名から、どこで契約したかを見分ける

明細の表示名で、AかBかCかがほぼ分かります【要確認：表示名はカード会社によって違う】。

| 明細の表示名 | 状況 | 次に見る場所 |
|---|---|---|
| APPLE.COM/BILL、アップル などで始まる | A | iPhoneの「設定」 |
| `GOOGLE *` などで始まる | B | 「Playストア」アプリ |
| サービスの名前そのもの（NETFLIX.COM など） | C（Webで直接） | サービスのWebサイト |
| カードの明細には出ず、スマホ料金の中にある | C（キャリア決済） | 携帯会社の会員ページ |

Aの「APPLE.COM/BILL」は、1行に複数のサブスクがまとまっていることがあります。中身はステップ3で確かめます。

## ステップ3：契約した場所ごとの画面で解約する

### Aの人：iPhoneの「設定」から解約する

1. iPhoneの「設定」アプリを開き、いちばん上の自分の名前を押します。
2. 「サブスクリプション」を押すと、契約中のものが一覧で出ます。
3. 解約したいものを押して、「サブスクリプションをキャンセル」を押します【要確認：ボタンの文言】。
4. 確認の画面で「確認」を押せば完了です。

一覧に見当たらない場合は、別のApple IDで契約している可能性があります。家族の端末で契約したものが、自分のカードに請求されていることも【要確認：ファミリー共有の支払いの仕組み】。購入の履歴は、パソコンで `https://reportaproblem.apple.com/` を開き、Apple IDでサインインしても見られます。

### Bの人：「Playストア」アプリから解約する

1. Androidで「Playストア」アプリを開きます。
2. 右上の自分のアイコン →「お支払いと定期購入」→「定期購入」を押します。
3. 解約したいものを選び、「定期購入を解約」を押します。
4. 理由を聞かれたら、どれかを選んで「次へ」→「定期購入を解約」で完了です【要確認：画面の流れ】。

パソコンからなら、`https://play.google.com/store/account/subscriptions` を開いても同じ一覧が出ます。iPhoneしか持っていない人でも、ここから確認できます。

### Cの人：Webで直接、またはキャリア決済

Webで直接契約している場合は、次の順で進めます。

1. 明細の表示名を検索欄に入れて、サービスの公式サイトを探します。入力例：`NETFLIX.COM 解約`
2. 公式サイトにログインしてください。ログインできないときは、契約に使いそうなメールアドレスで「パスワードを忘れた方」を試します。
3. 右上のアイコンや「アカウント」から、「プラン」「メンバーシップ」「契約内容」のような項目を開きます【要確認：サービスごとに名前が違う】。
4. 「解約」「キャンセル」「メンバーシップの終了」のようなボタンを押します。

キャリア決済（スマホ料金と一緒に払う方法）の場合は、携帯会社の会員ページで確かめます【要確認：各社の画面名】。

- ドコモ：「My docomo」にログイン →「d払い（ドコモ払い）」の利用状況
- au：「My au」にログイン →「auかんたん決済」の利用状況
- ソフトバンク：「My SoftBank」にログイン →「ソフトバンクまとめて支払い」の利用状況

ここで分かるのは、「どのサービスに払っているか」までです。解約そのものは、そのサービスの画面で行います。

## ステップ4：解約できたかを確かめる

1. 解約のあとに届く、確認のメールを探します。件名に「解約」「キャンセル」「定期購入」などが入っているはずです。
2. Aの人は、「設定」→ 自分の名前 →「サブスクリプション」で、そのサービスが「期限切れ」の側に移ったか、「〇月〇日に終了」と出ているかを見ます。
3. Bの人は、「定期購入」の一覧で「解約済み」と出ているかを見ます。
4. 翌月の明細で、同じ請求が出ていないかを確かめます。

## つまずきやすい箇所と、その対処

**解約したのに、まだ使える**
多くのサブスクは、解約しても、お金を払った期間の終わりまでは使えます。「〇月〇日に終了」と出ていれば、解約はできています。

**無料体験の途中で解約したら、すぐ使えなくなった**
無料体験は、解約した時点で終わるサービスがあります【要確認：サービスごとに違う】。体験期間を使い切りたいなら、終了の前日に解約するのが安全です。

**どの一覧にも見当たらない**

[ここに体験]

家族のスマホや、昔使っていた別のメールアドレスで契約している可能性があります。家族のiPhoneとAndroidでも、ステップ3のAとBを同じように確かめます。それでも見つからなければ、書式2でサービスに問い合わせます。

**何のサービスか、まったく心当たりがない**
自分も家族も契約していないなら、カードの不正利用の可能性があります。書式3でカード会社に連絡します。カードの裏面に書いてある電話番号が確実です。

## そのまま使える書式3つ

### 書式1：サブスクの書き出し表

メモ帳でも紙でもOKです。ステップ1で左の3列、ステップ2で「状況」、ステップ4で「解約日」を埋めます。

```
| 明細の表示名 | 金額 | 請求日 | 状況（A/B/C） | サービス名 | 続ける？ | 解約日 |
|---|---|---|---|---|---|---|
| （APPLE.COM/BILL） | （980円） | （毎月12日） | （A） | （〇〇アプリ） | （やめる） | （10/16） |
| （GOOGLE *YouTube） | （1,280円） | （毎月3日） | （B） | （YouTube Premium） | （続ける） | （ ） |
| （ ） | （ ） | （ ） | （ ） | （ ） | （ ） | （ ） |

毎月の合計：（ ）円 → 解約後：（ ）円
```

### 書式2：サービスへ、解約のしかたを問い合わせる文

サービスの「お問い合わせ」フォームに貼ります。

```
件名：契約中のプランの解約方法について

お世話になっております。
クレジットカードの明細に、貴社のサービスと思われる請求があり、
解約の手続きをしたいのですが、ログインしているアカウントが分からない状態です。

・明細の表示名：（NETFLIX.COM）
・金額：（1,590円）
・請求日：（毎月20日）
・カードの名義：（ヤマダ タロウ）
・カード番号の下4桁：（1234）
・使っていた可能性のあるメールアドレス：（taro@example.com）

該当するアカウントの確認と、解約の方法を教えていただけますでしょうか。
よろしくお願いいたします。
```

### 書式3：カード会社へ、心当たりのない請求を問い合わせるときのメモ

電話の前に埋めておくと、聞かれたことにすぐ答えられます。

```
【カード会社への問い合わせメモ】

・カードの名義：（ヤマダ タロウ）
・カード番号の下4桁：（1234）
・心当たりのない請求
  　明細の表示名：（〇〇〇〇）
  　金額：（980円）
  　請求日：（2026年10月12日／毎月）
・自分で確かめたこと：
  　iPhoneの「サブスクリプション」に（なし）
  　Google Playの「定期購入」に（なし）
  　家族のスマホにも（なし）

伝えること：
「この請求に心当たりがありません。どこからの請求か調べていただけますか」
```

## 終わったかどうかの確認方法

次の3つがそろえば完了です。

1. 書式1の「やめる」の行すべてに、解約日が入っている
2. 解約したものすべてで、確認のメールか「〇月〇日に終了」の表示を見た
3. 翌月の明細に、解約したサブスクの請求が出ていない

3は翌月にならないと確かめられないので、スマホのカレンダーに「明細を確認」と予定を入れておきます。

## この手順が終わった人が、次に困ること

自分の分は片づいても、家族の分が残っていることが多いんですよね。家族のスマホのサブスクが、同じカードで払われているケースです。

もう1つは、続けると決めたサブスクの更新日の管理です。年払いのものは1年後に急に大きな額が引き落とされます。書式1の表を、年に1回見直す日を決めておくと安心です。
