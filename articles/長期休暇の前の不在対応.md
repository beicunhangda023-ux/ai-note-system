# 長期休暇の前の不在対応｜自動応答・事前連絡・引き継ぎメモを4ステップで終わらせる

## 休み前の最終日、何から手をつけますか

夏休みまで、あと1週間。
「自動返信って、どこで設定するんだっけ」
「取引先には、いつ伝えればいいんだろう」

去年もやったはずなのに、手順をまったく覚えていない。結局、最終日の夕方に自動応答だけ入れて、休み中もスマホでメールを開いてしまう。そんな休みの入り方になっていませんか？

## この記事が向いていない人

- 会社で不在時の手順書やテンプレートが決まっていて、そのとおりに進めればいい人
- 休みが1〜2日だけで、自動応答を入れるほどではない人
- 会社のメールがOutlookでもGmailでもない人（画面の名前が合いません）

## 全体像：休みの2週間前に始めて、4ステップで終わります

[ここに体験]

使うものは、ふだん仕事で開いている3つだけです。

- 会社のメール（Outlook か Gmail）
- 予定表（Outlookの予定表 か Googleカレンダー）
- チャット（Teams か Slack。使っていなければ不要）

やることは4つです。

| いつ | ステップ | 時間の目安 |
|---|---|---|
| 2週間前 | 1. 止まると困る仕事を洗い出す | 20分 |
| 1週間前 | 2. 社外へ事前連絡を送る | 15分 |
| 3日前 | 3. 引き継ぎメモを作って渡す | 30分 |
| 前日 | 4. 自動応答とチャットのステータスを設定する | 15分 |

自動応答は、いちばん最後なんですよね。誰に引き継ぐか、取引先に何を伝えたかが決まって、はじめて文面が書けるからです。

逆の順番、つまり最終日に自動応答から入れると、こんなことが起きます。

- 自動応答に「急ぎは〇〇さんへ」と書いたのに、〇〇さんは何も聞いていない
- 取引先は自動応答ではじめて休みを知り、「先に言ってほしかった」となる
- 期間を指定し忘れて、休み明けも「不在です」と返し続ける

どれも、手順の順番を守れば防げます。

もうひとつ。全員が4つ全部やるわけではありません。社内のやり取りしかない人は、ステップ2を飛ばせます。逆に、自分が取引先の窓口になっている人は、ステップ2と3で「代わりの担当」を立てるひと手間が増えます。

## 有料部分に入っているもの

- 状況の分かれ方（社内だけ／社外の取引先がいる／自分が社外の窓口）と、それぞれで飛ばせるステップ
- 止まると困る仕事を、予定表とメールから洗い出す手順と記入表
- 社外への事前連絡を、Outlook・Gmailで予約送信する手順
- 引き継ぎメモを、Teams・Slack・共有フォルダで渡す手順
- Outlook（従来版・新しいOutlook）とGmailの自動応答の設定手順。社内向けと社外向けで文面を分ける方法
- TeamsとSlackのステータスの設定手順
- つまずきやすい箇所3つと、その対処
- そのまま使える書式3つ（Aの人向け：チームへの引き継ぎメモ／Bの人向け：社外への事前連絡メール／Cの人向け：代理の担当への依頼メール）
- 自動応答の入力例（社内向け・社外向け）
- 設定できたかを、自分で確かめる方法

ーーー ここから有料 ーーー

## 状況の分かれ方：自分がA・B・Cのどれかを決める

手順がいちばん変わるのは、休み中に連絡してくる相手がどこまで広がっているか、です。

| | 状況 | 当てはまる人の例 | やるステップ |
|---|---|---|---|
| A | 社内のやり取りだけ | 経理・総務・社内システムの担当 | 1 → 3 → 4（2は飛ばす） |
| B | 社外の取引先がいる | 取引先と月に数回メールする | 1 → 2 → 3 → 4 |
| C | 自分が社外の窓口で、代わりの担当が必要 | 営業・お客さま対応・発注の窓口 | 1 → 2 → 3 → 4（2と3で代理の担当を立てる） |

迷ったら、送信済みメールの直近1か月を見てください。会社以外のアドレスが1件もなければA。何件かあればBです。毎日のように社外とやり取りしているならCになります。

## ステップ1：休暇2週間前に「止まると困る仕事」を洗い出す

予定表とメールから、休み中に起きることを拾います。

1. Outlookなら、左下の「予定表」アイコンを押します。上の「表示」タブ →「ビューの変更」→「一覧」を選ぶと、予定が1行ずつ並びます【要確認：新しいOutlookでは「一覧」の場所が違う可能性】。
2. Googleカレンダーなら、右上の表示切り替え（「週」などと書かれたボタン）を押して「スケジュール」を選びます。
3. 休みの初日から、休み明けの3営業日目までの予定を全部見ます。
4. 次に、メールの検索欄で締切に関わる言葉を探します。
   - 入力例（Outlook）：`締切`、`期限`、`までに` を1つずつ
   - 入力例（Gmail）：`締切 OR 期限 after:2026/07/20`

見つけたものは、この表に書き出します。

| 日付 | 何が起きるか | 誰が関わるか | 止まると困るか |
|---|---|---|---|
| 8/12 | 月次レポートの提出 | A社 田中様 | 困る → 前倒しで出す |
| 8/13 | 発注の承認 | 社内 購買部 | 困る → 代理を頼む |

「困る」が付いた行が、ステップ2と3でやることです。Cの人は、この表を持って上司と「誰に代理を頼むか」を決めておきます。

## ステップ2：社外の取引先へ事前連絡メールを送る（B・Cの人）

送るのは休みの1週間前が目安です。早すぎると忘れられますし、前日では先方の調整が間に合いません。

1. ステップ1の表で、社外の人が関わる相手を宛先にします。
2. 本文は、下の「書式2」をそのまま使えます。
3. 取引先ごとに1通ずつ送ります。BCCでまとめて送ると、相手から見て「自分宛て」に感じにくいからです。

1週間前に送れないときは、予約送信で日時を決めておけます。

- 従来のOutlook：メール作成画面の「オプション」タブ →「配信タイミング」→「指定日時以降に配信」にチェック → 日時を入れて「閉じる」→「送信」
- 新しいOutlook・Web版：「送信」ボタン横の「∨」→「送信のスケジュール設定」【要確認】
- Gmail：「送信」ボタン横の「▼」→「送信日時を設定」

Cの人は、ここで代理の担当者の名前と連絡先も伝えます。代理の人には、このメールより先に「書式3」で依頼して、了承をもらっておきます。

## ステップ3：引き継ぎメモを作って、3日前に渡す

ステップ1の表から「困る」行だけを、引き継ぎメモに移します。形は「書式1」をそのまま使えます。

渡すときは、メモの置き場所を1か所に決めます。

- Teams：チームのチャネルの「ファイル」タブにアップロード → チャネルに投稿して、相手に「@メンション」を付けて知らせる
- Slack：チャンネルに投稿 → メッセージにカーソルを合わせて「…」→「チャンネルにピン留めする」【要確認：現在のメニュー名】
- 共有フォルダ：ファイルの場所（パス）をメールに貼って送る

渡すときは、メモを見せながら5分だけ口で説明すれば十分です。

## ステップ4：前日に自動応答とステータスを設定する

### 従来のOutlook（デスクトップ版）

1. 左上の「ファイル」→「自動応答」を押します。
2. 「自動応答を送信する」を選び、「次の期間のみ送信する」にチェックを入れます。
3. 「開始時刻」に休み初日の0:00、「終了時刻」に最終日の23:59を入れます。
4. 「所属組織内」タブに、社内向けの文面を貼ります。
5. 「所属組織外」タブを開き、「所属組織外の送信者に自動応答する」にチェック。「所属組織外のすべての送信者」を選んで、社外向けの文面を貼ります。
6. 「OK」を押します。

### 新しいOutlook・Outlook on the web

右上の歯車（設定）→「アカウント」→「自動応答」と進みます。「自動応答をオンにする」をオンにして、「期間を指定して返信を送信する」にチェックし、日時を入れます。社外にも返すなら「組織外の送信者に返信を送信する」にチェックします【要確認：項目名は更新で変わることがあります】。

### Gmail

1. 右上の歯車 →「すべての設定を表示」を押します。
2. 「全般」タブを下へスクロールして、「不在通知」を探します。
3. 「不在通知ON」を選び、「開始日」と「終了日」を入れます。
4. 「件名」には `【不在のお知らせ】8月16日まで休暇をいただいております` のように入れ、「メッセージ」に文面を貼ります。
5. 社内と社外で文面を分ける項目は見当たらないので、社外向けの文面1本で設定します【要確認】。
6. いちばん下の「変更を保存」を押します。

### 自動応答の入力例

社内向け（Outlookの「所属組織内」タブ）

```
（自分の名前）です。（8月16日）まで休暇をいただいています。（17日）から順に確認します。
急ぎの件は（代理の担当者名）さん（内線：〇〇）へお願いします。
```

社外向け（Outlookの「所属組織外」タブ、Gmailの「メッセージ」）

```
いつもお世話になっております。（△△株式会社）の（自分の名前）です。
（8月10日）〜（8月16日）は休暇のため不在にしております。
（8月17日）以降に順にお返事いたします。※このメールは自動で送信しています。
```

### TeamsとSlackのステータス

- Teams：右上の自分のアイコン →「ステータスメッセージを設定」→ 文面を入れて、「ユーザーが自分にメッセージを送信するときに表示する」にチェック。「次の期間後に消去」で休み明けの日を選び、「完了」を押す【要確認：現在の項目名】
- Slack：自分のアイコン →「ステータスを更新」→ 絵文字とひと言を入れ、「次の期間後に消去」で日付を選んで「保存」【要確認：アイコンの位置はバージョンで違う】

ステータスの入力例はこちら。

`8/16まで休暇中です。急ぎの件は佐藤さんへお願いします`

## つまずきやすい箇所と、その対処

**社外に自動応答が届いていない**
従来のOutlookで、「所属組織外」タブのチェックを入れ忘れていることが多いです。ステップ4の5番を見直してください。チェック欄が押せないなら、会社の設定で止められています。情報システムの担当に確認してください。

**休み明けになっても、自動応答が送られ続ける**
「次の期間のみ送信する」にチェックを入れずにオンにすると起きます。期間を指定しておけば、終了時刻で自動的に止まります。

**引き継いだ相手から、休み中に電話が来る**

[ここに体験]

引き継ぎメモに「迷ったときの判断」がないと、相手は聞くしかないんですよね。書式1の「迷ったときの判断」欄は、空けずに埋めてください。

## そのまま使える書式3つ

状況A・B・Cに1つずつ対応しています。自分の状況の書式から使ってください。（ ）の中を書き換えれば、そのまま使えます。

### 書式1（Aの人向け）：チームへの引き継ぎメモ

```
【休暇中の引き継ぎメモ】
作成：（自分の名前）／休暇：（8月10日〜8月16日）／復帰：（8月17日）

■ 期間中に起きること
・（8/12）（月末の支払データの締め）（経理部 鈴木さん）
　→ （8/7に入力済み。差し戻しが来たら、17日に直すと返信をお願いします）
・（8/13）（経費精算の承認依頼）（営業部）
　→ （承認不要。17日にまとめて対応します）

■ 迷ったときの判断
・お金が動く話 → （上司の名前）さんへ
・締切が休み中にある話 → 「担当が戻り次第対応します」と返す
・それ以外 → （17日）まで保留でOK

■ 資料の場所
（共有フォルダのパス、またはTeams・Slackのリンク）

■ どうしても連絡が必要なとき
（連絡してよい手段と時間帯。受けない場合は「連絡不要」と書く）
```

### 書式2（Bの人向け）：社外への事前連絡メール

Cの人は、「お急ぎのご用件は」から始まる4行を足して使います。

```
件名：【ご連絡】夏季休暇のため、（8月10日）〜（8月16日）は不在にいたします

（〇〇株式会社）
（〇〇様）

いつもお世話になっております。（△△株式会社）の（自分の名前）です。

誠に勝手ながら、（8月10日（月））から（8月16日（日））まで、夏季休暇をいただきます。
期間中にいただいたメールは、（8月17日（月））以降に順にお返事いたします。
なお、（8月7日（金））までにご依頼いただいた件は、休暇の前に対応いたします。

ご不便をおかけしますが、よろしくお願いいたします。
```

Cの人が足す4行

```
お急ぎのご用件は、下記の担当までご連絡ください。
担当：（代理の担当者名）
メール：（アドレス）
電話：（番号）
```

### 書式3（Cの人向け）：代理の担当への依頼メール

取引先へ連絡する前に、社内の代理の人へ送ります。

```
件名：【お願い】（8月10日〜16日）の休暇中、（A社）の窓口の代理をお願いできますか

（佐藤）さん

お疲れさまです。（自分の名前）です。
（8月10日〜16日）に夏季休暇をいただくため、その間の（A社）の窓口をお願いできないかと思い、ご連絡しました。

■ お願いしたいこと
・（A社 田中様）からの問い合わせへの一次返信（「担当が戻り次第回答します」でOKです）
・（8/13）の（発注書の受け取りと、共有フォルダへの保存）

■ 保留にしてほしいこと
・金額や納期を決める話

■ お渡しするもの
・引き継ぎメモ：（ファイルの場所）
・取引先の連絡先：（ファイルの場所）

取引先への事前連絡に（佐藤）さんのお名前を入れたいので、（8月3日）までにお返事をいただけると助かります。
上司の（〇〇）さんには了承をもらっています。

よろしくお願いします。
```

## 終わったかどうかの確認方法

休みの前日の夕方に、4つを確認します。

1. 私用のアドレスから会社のアドレスへメールを送り、社外向けの自動応答が返ってくるか
2. 同僚に社内から1通送ってもらい、社内向けの文面が返るか
3. TeamsやSlackで自分にメンションしてもらい、ステータスが表示されるか
4. ステップ1の表の「困る」行が、引き継ぎメモに全部移っているか

1と2は、期間を「翌日から」にしていると、前日のテストでは返ってきません。テストのときだけ期間の指定を外してオンにし、返ってきたのを確かめてから期間を指定し直します。

4つ全部にチェックが付けば、休みに入って大丈夫です。

## この手順が終わった人が、次に困ること

休み明けの朝の、数百件の未読メールです。どれから読むか、どれは読まずに済ませるか。ここで半日が消えることもあります。

引き継ぎメモの「期間中に起きること」を先に見て、その相手からのメールだけを先に開く。これだけで、最初の1時間はかなり楽になります。
