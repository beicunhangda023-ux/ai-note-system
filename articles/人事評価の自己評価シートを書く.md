# 人事評価の自己評価シートを書く｜達成・未達・途中で目標が変わった、の3パターン別

## 締切の前日、白紙のシートの前で止まっていませんか

評価シートの締切は明日。「目標に対する成果を記入してください」の欄は、まだ真っ白です。

半年前に立てた目標を見ても、何をしたか思い出せない。書けたとしても「がんばりました」くらいしか出てこない。毎回この状態で、締切ぎりぎりに数行だけ書いて出していませんか？

## この記事が向いていない人

- 評価シートの書き方を、上司や先輩に直接聞ける人（聞いたほうが早いです）
- 管理職として、部下の評価を書く側の人
- 評価制度そのもの（点数の付け方や、昇給との関係）を知りたい人

## 全体像：材料集めから面談の準備まで、4ステップで終わります

[ここに体験]

白紙で止まるのは、文章が苦手だからではないんですよね。書く材料が、手元にないからです。

半年分の仕事は、思い出そうとしても出てきません。でも、メール・予定表・チャットには全部残っています。そこから拾えば、書くことは自然に出てきます。

| ステップ | やること | 時間の目安 |
|---|---|---|
| 1 | 半年分の実績を、メール・予定表・チャットから拾い出す | 30分 |
| 2 | 拾った実績を「数字・行動・周りへの影響」の表に整理する | 20分 |
| 3 | 自分の状況に合った型で、文章にする | 30分 |
| 4 | 上司との面談の前に、聞かれそうなことを確認する | 10分 |

合わせて1時間半ほど。2日前に始めれば、締切の前日に慌てずに済みます。

使うものは3つです。

- 会社のメール（Outlook か Gmail）と予定表
- チャット（Teams か Slack。使っていなければ不要）
- Excel か、メモ帳（下書き用）

評価シートの画面そのもの（評価システム）は、会社ごとにまったく違います。この記事では、どの会社でも同じになる「材料集め」と「書き方」を中心に進めます。

## 有料部分に入っているもの

- 状況の分かれ方（目標を達成した／達成できなかった／途中で異動や担当変更があった）と、それぞれで書く中心の違い
- Outlook・Gmail・Teams・Slackで、自分の半年分の仕事を検索する手順と、検索欄への入力例
- 実績を整理する表（そのままExcelに写せる形）
- 「成果 → 行動 → 次の期」の順で書く手順と、言い換えの例
- 上司との面談の前に確認する5項目
- つまずきやすい箇所4つと、その対処
- そのまま使える文例3つ（達成したとき／未達のとき／途中で目標が変わったとき）

ーーー ここから有料 ーーー

## 状況の分かれ方：A・B・Cのどれで書くかを決める

書き方がいちばん変わるのは、目標に対して結果がどうだったか、です。

| | 状況 | 書く中心 | 使う文例 |
|---|---|---|---|
| A | 目標を達成した | どうやって達成したか（次の期もできる理由） | 文例1 |
| B | 目標を達成できなかった | どこまで進んだか、何を変えれば届くか | 文例2 |
| C | 期の途中で異動・担当変更があり、最初の目標が合わなくなった | 変更の経緯と、変更後に何をしたか | 文例3 |

目標が3つあって2つは達成、1つは未達。そんなときは、目標ごとにAとBを使い分けます。シート全体でどれか1つに決める必要はありません。

## ステップ1：半年分の実績を、メール・予定表・チャットから拾い出す

評価期間が2026年4月1日〜9月30日の場合の入力例で進めます。日付は自分の期間に置き換えてください。

### メール（Gmail）

検索欄に、次のように入れます。

`in:sent after:2026/03/31 before:2026/10/01`

自分が送ったメールだけが、期間で絞られて出てきます。さらに次の言葉を足すと、成果に近いメールが拾えます。

`in:sent after:2026/03/31 before:2026/10/01 完了 OR 納品 OR 提出 OR 報告`

### メール（Outlook）

1. 左のフォルダ一覧から「送信済みアイテム」を開きます。
2. 一覧の上の「並べ替え」（または「日付」）で、日付順に並べます。
3. 9月30日から4月1日まで、件名だけを上から流し読みします。

件名を追うだけでも、何をしていたかの大半は思い出せます。検索欄に `完了` や `提出` と入れて、送信済みアイテムの中を探す方法もあります。

### 予定表

Outlookの予定表でもGoogleカレンダーでも、表示を「月」に切り替えて、4月から1か月ずつ戻ります。会議の名前を見ると、関わった案件がそのまま並んでいるんです。

### チャット

- Slack：上の検索欄に `from:@自分の表示名 after:2026-03-31 before:2026-10-01 完了` と入れて検索
- Teams：上の検索欄に `完了` などを入れて Enter →「メッセージ」タブ →「フィルター」で差出人を自分にする【要確認：現在のフィルターの名前と位置】

拾ったものは、ステップ2の表に1行ずつメモしていきます。全部拾わなくて大丈夫です。目標1つにつき3件あれば書けます。

## ステップ2：拾った実績を「数字・行動・周りへの影響」の表に整理する

Excelを開いて、1行目に次の4つの見出しを入れます。

| A列：目標 | B列：数字 | C列：行動 | D列：周りへの影響 |
|---|---|---|---|
| 問い合わせへの初回返信を24時間以内に | 返信率96%（目標90%） | よくある質問の回答テンプレート10件を作った | 新人2名も同じテンプレートで返信できるようになった |
| 新規取引先を6社獲得 | 4社（67%） | 月10社に提案。提案書の型を作って作成時間を半分に | 提案書の型を課内で共有した |

数字がない仕事でも、数えられるものは意外とあります。

- 回数：定例会議の議事録を24回作成
- 件数：問い合わせ対応 月平均40件
- 時間：月次の集計作業を3時間 → 1時間に短縮
- 期日：締切の遅れ 0件

D列は空いていてもOKです。ただ、ここが埋まると評価のコメントにそのまま使われやすくなります。

## ステップ3：自分の状況に合った型で、文章にする

### 先に、欄の文字数の上限を確認する

評価システムの入力欄には、「0/400」のような残り文字数の表示があることが多いです【要確認：会社のシステムによる】。上限が分かったら、下書きはメモ帳かWordで書きます。システム上で長く書いていると、時間切れで入力が消えることがあるからです【要確認：システムによる】。

### 基本の型：成果 → 行動 → 次の期

1. 成果：ステップ2のB列を、1文で書く
2. 行動：C列を、2〜3文で書く
3. 次の期：今回の行動を、次にどう広げるかを1文で書く

### A・B・Cで変える部分

- A（達成）：「行動」を厚めに。同じことを次の期もできる、と読める書き方がゴールです。
- B（未達）：「成果」で進み具合を数字で書き、「未達の原因」を1文足します。原因は、自分で変えられる部分に絞ってOKです。
- C（途中で変更）：最初に「変更の経緯」を1文。そのあとに変更後の成果を書きます。前の担当の分は「引き継いだ」と書けば十分です。

### 言い換えの例

| 書きがちな言葉 | 言い換え |
|---|---|
| がんばりました | 毎朝9時に〇〇を確認する時間を固定しました |
| 努力しました | 提案書の型を作り、作成時間を半分にしました |
| 貢献できたと思います | 新人2名が、同じ手順で対応できるようになりました |

## ステップ4：上司との面談の前に、聞かれそうなことを確認する

提出したら、面談の前に5つだけ確認します。

1. 書いた数字の出どころ（メールや集計表）を、すぐに開けるか
2. 未達の原因が、「人のせい」に読めないか
3. 目標ごとに「次の期」の一文があるか
4. 上司が見ていない仕事も書いたか
5. 自分の評価（点数を付ける欄がある場合）と、文章の内容がずれていないか

4番は見落としがちなんですよね。上司は、自分が関わった仕事しか覚えていません。上司が見ていない仕事ほど、書く意味があります。

## つまずきやすい箇所と、その対処

**書くことが少なすぎる**
目標の欄以外に、「その他の取り組み」のような自由欄があるか確認します【要確認：シートによる】。目標外で引き受けた仕事は、そこに書けます。

**未達をどう書けばいいか分からない**
進み具合を、%か件数で書きます。「4社獲得（目標6社の67%）」のように。言い訳を長く書くより、次の期の具体的な手を1つ書くほうが伝わります。

**盛りすぎてしまう**

[ここに体験]

面談で「この数字はどこから？」と聞かれて答えられないものは、書かないでおきます。ステップ4の1番が、その確認です。

**去年のシートが見つからない**
提出の前に、シートをPDFかスクリーンショットで保存しておきます。保存先は「評価_2026上期」のように、年と期が分かるフォルダ名にしておくと、次の期にすぐ開けます。

## そのまま使える文例3つ

（ ）の中を自分の内容に書き換えて使います。見出しの【 】は、シートの欄が分かれていれば消してください。

### 文例1：目標を達成したとき

```
【成果】
（4〜9月）の（問い合わせへの初回返信率）は（96%）で、目標の（90%）を達成しました。

【行動】
（よくある質問10件の回答テンプレート）を作り、チームで共有しました。
あわせて、（毎日9時と13時に問い合わせを確認する時間）を予定表に固定しました。

【次の期】
（テンプレートを20件に増やし、新しく入った2名も同じ速さで返信できる状態）を目指します。
```

### 文例2：目標を達成できなかったとき

```
【成果】
（新規取引先の獲得）は（4社）で、目標（6社）の（67%）にとどまりました。

【行動】
（月10社への提案）を続け、（提案書の型を作って作成時間を半分）にしました。

【未達の原因】
（提案から契約までに平均2か月かかり、7月以降の提案が期内の契約に間に合いませんでした）。

【次の期】
（提案の時期を前倒しし、期の前半3か月で8社へ提案します）。
```

### 文例3：期の途中で異動・担当が変わったとき

```
【変更の経緯】
（7月）に（〇〇課）へ異動し、担当が（△△）に変わりました。
当初の目標（□□）は、（6月末）までの分を（前任の××さん）へ引き継いでいます。

【変更前（4〜6月）の成果】
（□□を3件完了しました）。

【変更後（7〜9月）の成果】
（△△の立ち上げで、業務手順書5本を作成しました）。
（異動から2か月で、一人で対応できる業務が全体の7割になりました）。

【次の期】
（△△の残り3割を一人で回せる状態にし、手順書を課内で共有します）。
```

## 終わったかどうかの確認方法

提出ボタンを押す前に、次の4つを確認します。

1. すべての目標に、「成果」が数字か具体的な事実で書かれている
2. すべての目標に、「次の期」の一文がある
3. どの欄も、文字数の上限に収まっている
4. 書いた内容の控え（PDFかスクリーンショット）を、年と期が分かるフォルダに保存した

提出したあとは、システム上の状態が「提出済み」のような表示に変わったかを見ます【要確認：表示はシステムによる】。変わっていなければ、下書き保存のままになっている可能性があります。

## この手順が終わった人が、次に困ること

上司との面談で、上司の評価と自分の評価がずれたときに、どう話すかです。

もう1つは、次の期の目標の立て方。今回、数字で書けなかった目標は、立てた時点で「何を数えるか」が決まっていなかったはずです。次の目標を立てるときに、ステップ2の表のB列を先に決めておく。これだけで、半年後の自己評価がかなり楽になります。
