# 機種変更のとき、2段階認証アプリを新しいスマホへ移す｜旧端末あり・OS変更・旧端末なしの3パターン

## 新しいスマホで、ログインの6桁が出てこない

新しいスマホが届いて、LINEも写真も移せた。ところが、会社のMicrosoft 365にログインしようとしたら「認証アプリのコードを入力してください」。新しいスマホの認証アプリを開いても、中は空っぽ。古いスマホは、明日には下取りに出す予定です。

## この記事が向いていない人

- 認証アプリ（ログインのときに6桁の数字を出すアプリ）を使っていない人。SMSで届くコードだけの人は、電話番号を引き継げば済みます
- 会社のスマホを、情報システムの担当がまとめて入れ替えてくれる人
- パスワードそのものの整理をしたい人（それは別の手順になります）

## 全体像：古いスマホを手放す前に、4ステップで終わります

[ここに体験]

いちばん大事なのは、順番なんですよね。先に古いスマホを初期化すると、認証アプリの中身も一緒に消えます。新しいスマホに移す前に消してしまうと、サービスごとに「本人確認のやり直し」が必要になり、数日かかることもあります。

| ステップ | やること | 時間の目安 |
|---|---|---|
| 1 | 認証アプリに入っているサービスを書き出す | 10分 |
| 2 | 新しいスマホへ移す（状況で方法が変わる） | 15〜60分 |
| 3 | すべてのサービスで、新しいスマホのコードでログインできるか確かめる | 20分 |
| 4 | 古いスマホから認証アプリを消して、手放す | 5分 |

4が終わるまで、古いスマホは手元に置いておきます。下取りの発送日が決まっている人は、その2日前までにステップ3を終わらせる計算で始めてください。

この記事で扱う認証アプリは、次の2つです。

- Google Authenticator（グーグル認証システム）
- Microsoft Authenticator（マイクロソフト認証アプリ）

ほかの認証アプリでも考え方は同じですが、画面の名前は違います。

## 有料部分に入っているもの

- 状況の分かれ方（旧端末があり同じOS／旧端末はあるがOSが変わる／旧端末が手元にない）と、それぞれの移し方
- 認証アプリに入っているサービスを書き出す手順と、記入表
- Google Authenticatorを、Googleアカウントの同期とQRコードで移す手順
- Microsoft Authenticatorを、バックアップから戻す手順
- OSが変わるときに、サービスごとに登録し直す手順（Googleアカウント・Microsoftの職場アカウントの画面名つき）
- 古いスマホがないときに、バックアップコードで入る手順と、会社への頼み方
- すべてのサービスで、新しいスマホのコードを使ってログインできるかを確かめる手順
- つまずきやすい箇所4つと、その対処
- そのまま使える書式3つ（サービスの書き出し表／バックアップコードの保管シート／情報システム担当への依頼文）

## 状況の分かれ方：A・B・Cのどれかを決める

移し方を左右するのは、古いスマホの状態です。

| | 状況 | 移し方 |
|---|---|---|
| A | 古いスマホが手元にあり、同じOSへ移る（iPhone→iPhone、Android→Android） | アプリの同期やバックアップで、まとめて移せる |
| B | 古いスマホは手元にあるが、OSが変わる（iPhone⇔Android） | Google AuthenticatorはQRコードで移せる。Microsoft Authenticatorは、サービスごとに登録し直す【要確認】 |
| C | 古いスマホが故障・紛失・初期化済みで、手元にない | バックアップコードやSMSで入り直し、新しいスマホを登録する |

AとBの人は、ステップ2で自分の欄だけ読めばOKです。Cの人は、ステップ1を飛ばしてステップ2のCへ進んでください。

## ステップ1：認証アプリに入っているサービスを書き出す

1. 古いスマホで認証アプリを開きます。
2. 並んでいるサービスの名前と、その下のアカウント名（メールアドレスなど）を、「書式1」の表に1行ずつ書き写します。
3. 各サービスで、バックアップコード（認証アプリが使えないときのための予備の番号）を保存しているかを確認し、表の「バックアップコード」欄に「あり／なし」を書きます。

この表は、ステップ3で漏れがないかを見るのに使います。

## ステップ2：新しいスマホへ移す

### Aの人：同じOSへ移る

**Google Authenticatorの場合**

1. 古いスマホでGoogle Authenticatorを開き、右上の丸いアイコンを押します。
2. Googleアカウントでログインしていれば、コードはGoogleアカウントに同期されています【要確認：同期の表示のされ方】。
3. 新しいスマホでGoogle Authenticatorを入れ、同じGoogleアカウントでログインします。
4. 古いスマホと同じサービスが並んだら完了です。

同期を使いたくない場合は、Bの人と同じQRコードの方法でも移せます。

**Microsoft Authenticatorの場合**

1. 古いスマホでMicrosoft Authenticatorを開き、右上の「…」（Androidは「⋮」）→「設定」を押します。
2. 「バックアップ」の項目で、iPhoneなら「iCloudバックアップ」、Androidなら「クラウドバックアップ」をオンにします【要確認：項目名】。Androidでは、個人用のMicrosoftアカウントが必要です。
3. 新しいスマホでMicrosoft Authenticatorを入れ、最初の画面で「回復の開始」（または「バックアップから復元」）を押します【要確認：ボタン名】。
4. 同じアカウントでログインすると、中身が戻ります。

会社のアカウントは、戻したあとに「追加の確認が必要」と出ることがあります【要確認】。そのときはBの「会社のMicrosoftアカウント」の手順へ進みます。

### Bの人：OSが変わる

**Google Authenticatorの場合（QRコードで移す）**

1. 古いスマホでGoogle Authenticatorを開き、メニュー（右上の「⋮」または左上の「≡」）→「アカウントを移行」→「アカウントをエクスポート」を押します【要確認：メニューの位置と名前】。
2. 移したいサービスにチェックを入れて「次へ」。画面にQRコードが出ます。
3. 新しいスマホでGoogle Authenticatorを開き、「アカウントをインポート」（または「既存のアカウントをインポート」）→「QRコードをスキャン」を押して、古いスマホのQRコードを読み取ります【要確認：ボタン名】。

**Microsoft Authenticatorの場合（サービスごとに登録し直す）**

iPhoneのバックアップは、Androidでは戻せません（逆も同じ）【要確認】。サービスごとに、パソコンから新しいスマホを登録し直します。

会社のMicrosoftアカウント（Microsoft 365）の場合

1. パソコンで `https://mysignins.microsoft.com/security-info` を開き、会社のアカウントでログインしてください。
2. 「セキュリティ情報」の画面で「サインイン方法の追加」を押します。
3. 「Microsoft Authenticator」（または「認証アプリ」）を選び、「次へ」を押すとQRコードが出ます。
4. 新しいスマホのMicrosoft Authenticatorで「＋」→「職場または学校アカウント」→「QRコードをスキャン」を押して読み取ります。
5. 一覧に新しいスマホが追加されたのを確かめてから、古いスマホの行を「削除」します。

この画面が使えない会社もあります。その場合は書式3で情報システム担当に頼みます。

Googleアカウントの場合

1. パソコンで `https://myaccount.google.com/` を開き、左の「セキュリティ」を押します。
2. 「2段階認証プロセス」を押し、パスワードを入れます。
3. 「認証システム」→「認証システム アプリを変更」を押すとQRコードが出ます【要確認：現在のボタン名】。
4. 新しいスマホの認証アプリで読み取り、出てきた6桁を画面に入れて「確認」を押します。

Amazon・Instagramなども流れは同じです。設定画面の「2段階認証」や「セキュリティ」から、「認証アプリを変更」のような項目を探します。

### Cの人：古いスマホが手元にない

1. 各サービスのログイン画面で、6桁を入れる画面の下にある「別の方法を試す」「その他のオプション」などを押します【要確認：サービスごとに名前が違う】。
2. 「バックアップコードを入力」を選び、保存しておいたバックアップコードを入れます。
3. ログインできたら、すぐにBの手順で新しいスマホを登録します。
4. 使ったバックアップコードは、1回使うと無効になるものが多いです【要確認】。新しいバックアップコードを発行して、「書式2」に書き直してください。

バックアップコードもSMSも使えない場合は、サービスごとの「アカウントの復元」の手続きになります。Googleなら `https://accounts.google.com/signin/recovery` から始めます。審査に数日かかることがあり、必ず戻れるとは限りません【要確認】。

会社のアカウントは、書式3で情報システム担当に連絡します。

## ステップ3：すべてのサービスで、ログインできるか確かめる

1. パソコンのブラウザで、シークレットウィンドウ（ログイン情報を残さない画面）を開きます。Chromeなら右上の「⋮」→「新しいシークレット ウィンドウ」です。
2. 書式1の表の上から順に、各サービスにログインします。
3. 6桁を聞かれたら、新しいスマホの認証アプリのコードを入れます。
4. ログインできたら、表の「新しいスマホで確認」欄に日付を書きます。

全部の行に日付が入るまで、ステップ4には進みません。

## ステップ4：古いスマホから認証アプリを消して、手放す

1. 古いスマホで認証アプリを開き、各サービスを削除します（Google Authenticatorなら、サービスを長押し →「削除」【要確認】）。
2. アプリ自体をアンインストールします。
3. そのあとで、スマホの初期化をします。

アプリを先に消しておけば、初期化をし損ねても6桁のコードは残りません。

## つまずきやすい箇所と、その対処

**移したのに、新しいスマホのコードが「正しくない」と言われる**
スマホの時刻がずれていると、コードが合わなくなります。iPhoneは「設定」→「一般」→「日付と時刻」→「自動設定」をオン。Androidは「設定」→「システム」→「日付と時刻」→「日時を自動的に設定」をオンにします【要確認：Androidは機種によって場所が違う】。

**会社のアカウントだけ、どうしてもログインできない**

[ここに体験]

会社のアカウントは、会社の設定で「本人が登録し直すこと」を止めている場合があります。自分で何度も試すとアカウントがロックされることもあるので、2回失敗したら書式3で連絡するほうが早いです。

**バックアップコードをどこに保存したか分からない**
パソコンの「ダウンロード」フォルダに、`Backup-codes-〇〇.txt` のような名前で残っていることがあります【要確認：ファイル名はサービスによる】。見つからなければ、ログインできている今のうちに新しく発行して、書式2に控えます。

## そのまま使える書式3つ

### 書式1：認証アプリに入っているサービスの書き出し表

紙でも、スマホのメモでもOKです。ステップ1で書き、ステップ3で日付を埋めます。

```
| No. | サービス名 | アカウント名 | バックアップコード | 新しいスマホで確認 |
|---|---|---|---|---|
| 1 | （Microsoft 会社） | （taro@会社.co.jp） | （なし） | （10/18） |
| 2 | （Google） | （taro@gmail.com） | （あり） | （10/18） |
| 3 | （Amazon） | （taro@gmail.com） | （なし） | （ ） |
| 4 | （ ） | （ ） | （ ） | （ ） |
```

### 書式2：バックアップコードの保管シート

印刷して、通帳などと同じ場所にしまいます。スマホの中だけに置くと、なくしたときに一緒に失います。

```
【バックアップコード保管シート】 更新日：（2026年10月18日）

■ サービス：（Google）
  アカウント：（taro@gmail.com）
  コード：（ここに書き写す。または印刷したものを貼る）
  使ったコード：（使ったら線を引く）

■ サービス：（ ）
  アカウント：（ ）
  コード：（ ）
  使ったコード：（ ）

※ 機種変更をしたら、この日付を更新する
```

### 書式3：情報システム担当へ、認証の登録し直しを頼むメール

```
件名：【依頼】機種変更に伴う多要素認証の再登録のお願い（（自分の名前））

情報システム（担当）の皆さま

お疲れさまです。（部署名）の（自分の名前）です。

（10月17日）にスマートフォンを機種変更したところ、
会社アカウントの認証アプリ（Microsoft Authenticator）が移せず、
サインインができない状態です。

・アカウント：（taro@会社.co.jp）
・旧端末：（iPhone 13）（手元に（あり／なし））
・新端末：（Pixel 9）
・試したこと：（バックアップからの復元。エラー「〇〇」が表示）

認証方法の再登録をお願いできますでしょうか。
必要な手続きや、お伺いする日時があれば教えてください。

よろしくお願いいたします。
```

## 終わったかどうかの確認方法

次の4つがそろえば完了です。

1. 書式1の表の「新しいスマホで確認」欄が、全部の行で埋まっている
2. 会社のアカウントの「セキュリティ情報」画面に、新しいスマホが登録されている
3. バックアップコードを使ったサービスは、新しいコードを書式2に書き直した
4. 古いスマホの認証アプリを消してから、初期化した

## この手順が終わった人が、次に困ること

認証アプリは移せても、パスワードがブラウザ、スマホ、メモ帳に散らばったまま、という人が多いんですよね。機種変更のたびにログインで止まるなら、次はパスワードを1か所にまとめる番です。書式1の表は、そのときのサービス一覧としてそのまま使えます。
