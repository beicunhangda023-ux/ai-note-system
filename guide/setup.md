# skillファイル 使い方ガイド — セットアップ手順

このガイドは、ai-note-systemを自分専用にカスタマイズして使うための手順です。
よくある質問は `guide/faq.md` を参照してください。

---

## ファイル構成

```
ai-note-system/
├── CLAUDE.md              ← 発信者プロフィール（最初に設定）
├── skills/
│   ├── style/
│   │   ├── SKILL.md       ← 文体ルール（最重要）
│   │   └── forbidden.md   ← 禁止表現・校正チェック
│   ├── feedback/
│   │   └── feedback.md    ← 修正記録（使うたびに育つ）
│   ├── note_auto.md       ← /note_auto コマンドの定義
│   └── learn.md           ← /learn コマンドの定義
├── guide/
│   ├── setup.md           ← セットアップ手順（このファイル）
│   └── faq.md             ← よくある質問
└── workspace/             ← 出力先（触らなくてOK）
```

---

## STEP1：フォルダをパソコンに置く

ダウンロードした `ai-note-system` フォルダを、パソコンのわかりやすい場所に置いてください。

おすすめの場所：
- Mac：書類フォルダ（~/Documents/ai-note-system）
- Windows：ドキュメントフォルダ

**注意：フォルダは途中で移動しないでください。**
Claude Codeが参照できなくなる場合があります。

---

## STEP2：CLAUDE.md を自分用に書き換える

`CLAUDE.md` を開いて、（）の中を自分の情報に書き換えます。

書き換える箇所：

```
## 私は誰か
- 名前：（自分のペンネームや名前）
- 属性：（自分のプロフィール）
- 発信テーマ：（自分のテーマ）

## 読者は誰か
- （自分の読者像）
```

「発信スタンス」と「最優先事項」は、そのまま使ってもOKです。

---

## STEP3：skills/style/SKILL.md を自分用に書き換える

`skills/style/SKILL.md` を開いて、自分の文体に合わせます。

**最低限書き換える箇所（2箇所だけ）：**

### ① よく使う言い回し

自分がよく使う語尾・言い回しに書き換えます。

```
## よく使う言い回し
- （自分がよく使う言葉1）
- （自分がよく使う言葉2）
- ...
```

**コツ：**過去に自分が書いた文章を読み返して、
「いい感じだな」と思った文末をそのまま抜き出すだけでOKです。

---

### ② 語尾のルール（メイン語尾）

「よく使う言い回し」と同じ語尾を、メイン語尾のリストにも書き換えてください。

---

## STEP4：Claude Codeでフォルダを開く

Claude Codeのデスクトップアプリを起動して、「Codeタブ」を開きます。

「Select a project」から `ai-note-system` フォルダを選択します。

これで、Claude Codeがフォルダ内のファイルを読み込んだ状態になります。

---

## STEP5：/note_auto を試す

チャット欄に以下を送ってみてください。

```
/note_auto

テーマ：（書きたいnoteのテーマ）
ターゲット：（誰向けか）
文字数：2,000〜2,500字
```

STEP3（構成確認）で「OK」と送れば、あとは自動で初稿まで出てきます。
