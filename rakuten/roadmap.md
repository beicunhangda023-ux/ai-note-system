# 楽天アフィの1人AI会社：月7桁までのロードマップ

最終更新：2026-10-23

---

## 0. 先に結論

- 月7桁（月100万円以上）は、**この計画で約束できる数字ではありません**。どこまで届くかは、集まる人の数で決まります。
- このロードマップは、「月7桁に必要な数」を先に計算し、そこへ**段階ごとの判定ライン**で近づく形にしています。判定ラインを越えなければ、次の段階に進みません。
- Claude Codeに任せるのは「調べる・下書きする・点検する・集計する」の4つです。**体験を書くことと、最後の公開ボタンはKODAIが持ちます。**
- 理由は2つあります。CLAUDE.mdの「体験を推測や創作で埋めない」というルール。そして、AIで大量に作った中身の薄いページは、Googleのスパムポリシー（大量生成コンテンツの不正使用）に当たるおそれがあるからです。

## 1. 月7桁に必要な数（逆算）

### 1-1. 楽天アフィリエイトの基本条件

| 項目 | 内容 | 確度 |
|---|---|---|
| 料率（紹介料の割合） | 楽天市場は商品ジャンルごとに2〜4% | 公式ガイドラインの記載を検索で確認。原文は【要確認】 |
| 報酬の上限 | 1商品あたり1,000円まで、同じ購入者からは月3,000円まで（料率アップ対象の商品は対象外） | 同上。【要確認】 |
| 成果になる条件 | リンクを押してから24時間以内にカートへ入れ、89日以内に購入 | 解説記事で確認。【要確認】 |
| 受け取り方 | 楽天キャッシュ（楽天ペイ残高）。3か月続けて月3,001円以上なら、申し込みで銀行振込に切り替えできる | 公式ページの記載を検索で確認。【要確認】 |

**上限があるので、高い商品を1つ売っても報酬は伸びません。** 10万円のパソコンが3%で売れても、報酬は3,000円ではなく1,000円で止まる計算です。月7桁は「少額の成果を大量に積む」形になります。

### 1-2. 計算

下の表の「仮定」は、いまはKODAIの実測がないため置いた数字です。**フェーズ1の実測値が出たら、必ず置き換えます。**

| 段階 | 数 | 計算 |
|---|---|---|
| 目標の報酬 | 月1,000,000円 | ― |
| 平均料率 | 3%（仮定） | 2〜4%の真ん中 |
| 必要な売上（購入された金額の合計） | 月33,333,333円 | 1,000,000 ÷ 0.03 |
| 1件あたりの購入金額 | 5,000円（仮定） | ― |
| 必要な購入件数 | 月6,667件（1日約222件） | 33,333,333 ÷ 5,000 |
| リンクを押した人のうち買う割合 | 2%（仮定） | ― |
| 必要なリンクのクリック数 | 月333,350回（1日約11,100回） | 6,667 ÷ 0.02 |
| ページを見た人のうちリンクを押す割合 | 10%（仮定） | ― |
| 必要な閲覧数 | 月約333万回 | 333,350 ÷ 0.1 |

**月333万回の閲覧は、会社員の副業1人分としては大きな数字です。** 計算上はこうなる、というだけで、届く保証はありません。ここを正直に置いたうえで、段階を刻みます。

### 1-3. 月7桁までの判定ライン（仮置き）

| フェーズ | 期間の目安 | 判定ライン（これを越えたら次へ） | 中身 |
|---|---|---|---|
| 0 準備 | 〜2週間 | 下の「準備チェック」が全部埋まる | 登録・ルール確認・媒体決め |
| 1 手作業で型を作る | 1〜3か月 | 成果1件以上。実測のクリック率・購入率が取れる | 自分が買った物だけで10〜30本 |
| 2 半自動化 | 3〜6か月 | 3か月続けて月3,001円以上（銀行振込に切り替えできる水準） | Claude Codeで調べる・下書き・点検・集計 |
| 3 勝ちパターンの拡大 | 6〜12か月 | 月10万円 | 売れた型だけを横に広げる |
| 4 月7桁への挑戦 | 12か月〜 | 月100万円 | 媒体を増やす・人に頼む・独自の検証データ |

期間はあくまで目安です。**判定ラインを越えないまま、次のフェーズの作業を始めないこと。** これがいちばん時間を無駄にしないルールです。

## 2. フェーズ0：準備（〜2週間）

### 準備チェック

- [ ] 勤務先の就業規則で、副業が認められているか確認した
- [ ] 楽天会員に登録し、楽天アフィリエイトの利用を始めた（楽天アフィリエイトのサイトから）
- [ ] 報酬の受け取りに必要なもの（楽天カードの発行、または楽天銀行口座と楽天IDのひも付け）を確認した【要確認：3,001円以上を受け取る場合の条件】
- [ ] 楽天アフィリエイトの「パートナー規約」と「ガイドライン」を読み、禁止事項を `rakuten/rules_memo.md` に書き写した
- [ ] ステマ規制（2023年10月施行。広告なのに広告と分からない表示を禁止するルール）に合わせて、全ページに「PR」「広告」を表示する形を決めた
- [ ] 副業の所得が年20万円を超えたら確定申告が必要になる、と把握した（住民税の申告は別に必要）【要確認：自分の条件での扱い】
- [ ] 最初の媒体を1つだけ決めた（下の3つから）

### 最初の媒体の選び方

| | A：ブログ | B：楽天ROOM | C：SNS（Instagram・X） |
|---|---|---|---|
| 向いている人 | 文章を書くのが苦にならない | 写真と短いコメントで進めたい | すでにフォロワーがいる |
| 立ち上がり | 遅い（検索に出るまで数か月）【要確認】 | 早い | フォロワー数しだい |
| 自動化のしやすさ | 高い（下書き・点検・集計） | 低い。自動投稿の扱いは規約で【要確認】 | 中くらい。同じ投稿の繰り返しは楽天のガイドラインでスパム扱い |
| 月7桁までの伸びしろ | 検索の閲覧数を積める | ROOM内の人気しだい | フォロワー数が上限になる |

迷ったら **A：ブログ** にします。Claude Codeで手伝える範囲がいちばん広いからです。

## 3. フェーズ1：手作業で型を作る（1〜3か月）

ここでは自動化しません。**「何が売れるか」を自分の数字で知る**のが目的です。

1. 過去1年の楽天市場の購入履歴を開き、「人にすすめられる物」を20個書き出す（楽天市場 → 購入履歴）
2. 20個から、使い続けている物を10個に絞る
3. 1商品1ページで書く。中身は「買う前の迷い → 比べた候補 → 使って分かったこと → 向いていない人」
4. 商品リンクは楽天アフィリエイトの管理画面で作る（商品ページのURLから作れる）【要確認：2026年時点の画面名】
5. 全ページの先頭に「PR」を表示する
6. 週に1回、成果レポートを見て `rakuten/kpi_sheet.md` に数字を写す

### このフェーズの判定

- 成果が1件以上ある
- 「閲覧数 → クリック数 → 購入件数」の実測値が3つそろった
- そろったら、1-2の表の「仮定」を実測に置き換え、月7桁に必要な閲覧数を計算し直す

## 4. フェーズ2：Claude Codeで半自動化（3〜6か月）

手作業で回っている工程のうち、**時間がかかっている順に**任せていきます。

| 工程 | 自動化の中身 | 人が残す部分 |
|---|---|---|
| 調べる | 楽天ウェブサービスのAPI（商品情報を取り出す公式の窓口）で、ランキング・価格・レビュー数をCSVにする | どれを書くかを選ぶ |
| 下書き | KODAIの購入メモと商品データから、ページの骨組みを作る | 体験の部分を書く |
| 点検 | PR表記の有無、禁止表現、価格を断定していないか、リンク切れ | 最後に読んで公開する |
| 集計 | 成果レポートから週次の数字表を作る | 次の手を決める |

### Claude Codeでの作業順

1. 楽天ウェブサービスでアプリを登録し、アプリケーションID・アフィリエイトID・アクセスキーを取る
   - 2025年以降、接続先が `app.rakuten.co.jp` から `openapi.rakuten.co.jp` へ移り、アクセスキーとReferer（どのサイトからの呼び出しかを示す情報）が必要になった、という解説があります【要確認：公式の移行案内】
   - IDやキーはリポジトリに書かず、環境変数に入れる
2. `scripts/fetch_items.py` を作り、商品検索とランキングの結果をCSVで保存する（Claude Codeに作らせる）
3. `scripts/check_page.py` を作り、下の点検項目を自動で見る
   - 先頭に「PR」または「広告」がある
   - 「治る」「必ず痩せる」などの効果を断定する表現がない（健康食品・化粧品は薬機法の対象）【要確認：対象表現の一覧】
   - 価格に「記事作成時点」と添えてある
4. `/rakuten_team 週次` で、リサーチ → 下書き → 点検 → 集計を1回で回す（`skills/rakuten_team.md`）

### 自動化しないもの

- 体験談の生成。使っていない商品のページ
- 同じ文面の投稿を、同じSNSで繰り返すこと（楽天のガイドラインでスパム扱い）
- 人が読まずに公開する、量産ページ
- レビューや口コミの作成

## 5. フェーズ3：勝ちパターンの拡大（6〜12か月）

1. `kpi_sheet.md` で、成果が出ているページの上位20%を選ぶ
2. その共通点を1行で書く（例：「買い替えの比較」「季節の消耗品」）
3. 共通点が同じ商品だけを、フェーズ2の流れで増やす
4. 楽天市場の大型セール（お買い物マラソン、楽天スーパーSALEなど）の前に、該当ページを更新する予定を入れる【要確認：開催の時期】
5. 成果が出ないページは、3か月で手直しか削除を決める

---

## 6. フェーズ4：月7桁への挑戦（12か月〜）

フェーズ3で月10万円に届いた場合だけ、ここに進みます。月10万円から月100万円は、閲覧数がおよそ10倍要る計算です。

選ぶ手は、次のどれか1つずつ。同時に全部はやりません。

- 媒体を1つ足す（ブログならROOMかSNS）
- 自分で比較・検証したデータ（同じジャンルの商品を並べて使った結果）を作る。AIに真似されにくい部分です
- 撮影や外注を人に頼む。報酬の何%まで使うかを先に決める
- 楽天アフィリエイト以外の報酬（メーカー直の案件など）を混ぜる

ここまで来たら、会社員を続けるか、開業届を出すかの判断も出てきます。それはこのロードマップの外で、税理士など専門の人に相談します。

6. 楽天アフィリエイトの管理画面で、リンクを作る画面の名前と、成果レポートをCSVで出せるか

8. 大型セールの開催時期
9. ブログが検索に出るまでの期間
10. 1-2の表の「仮定」4つ（平均料率・1件の金額・購入率・クリック率）。実測で置き換える
