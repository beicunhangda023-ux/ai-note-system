# /sns_team コマンド

## このコマンドの役割

SNS運用を「1人6役」で回すためのチーム構成です。
発信者（KODAI）1人で運用していても、それぞれの役割になりきってClaudeに考えさせることで、
戦略・企画・編集・マーケ・進行管理を漏れなくカバーできます。

CLAUDE.md（発信者プロフィール）を土台に、各役割が判断・提案を行います。

---

## チーム構成

| 役割 | 担当ファイル | 役割の一言 |
|---|---|---|
| 戦略責任者 | `skills/sns_team/roles/strategy.md` | 発信方針・方向性の設計 |
| リサーチ担当 | `skills/sns_team/roles/research.md` | 競合分析・市場調査 |
| 企画担当 | `skills/sns_team/roles/planning.md` | 投稿企画・ネタ出し |
| 編集担当 | `skills/sns_team/roles/editing.md` | 投稿作成・改善提案 |
| マーケティング担当 | `skills/sns_team/roles/marketing.md` | note導線・販売設計 |
| 秘書担当 | `skills/sns_team/roles/secretary.md` | タスク管理・進行管理 |

## 使い方

### 1. 特定の役割だけ呼び出す

```
/sns_team 戦略
/sns_team リサーチ
/sns_team 企画
/sns_team 編集
/sns_team マーケ
/sns_team 秘書
```

呼び出された役割は、対応する `roles/*.md` の指示に従って動きます。

### 2. チーム全体で1週間分の運用サイクルを回す

```
/sns_team 週次
```

このモードでは、以下の順番で全役割を通しで実行します。

1. **秘書**が今週のタスク状況を整理（進行中・未着手・遅延）
2. **戦略責任者**が今週の発信方針にズレがないか確認
3. **リサーチ担当**が直近の競合・トレンドを整理
4. **企画担当**がリサーチをもとに投稿ネタを5〜7個出す
5. **編集担当**が企画から実際の投稿文を作成
6. **マーケティング担当**がnoteへの導線・CTAを設計
7. **秘書**が今週分をタスクリストにまとめて締める

各ステップの出力後、次に進んでいいか確認します。
「OK」と送ると次のステップに進みます。

---

## 全役割共通のルール

- CLAUDE.md の発信スタンス・最優先事項を必ず守る
- skills/style/SKILL.md の文体ルールに従う（投稿文を書くときのみ）
- 煽らない・誇大にしない・誠実に伝える
- 会社員読者が「時間がない中でも動ける」提案にする
- 迷ったら、役割を混同せず自分の担当範囲だけを出力する
