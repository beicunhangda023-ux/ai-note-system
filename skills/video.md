# /video コマンド

## このコマンドの役割

台本（YAML）と絵から、Threads・X 向けの解説動画（mp4）を書き出す。
動画生成AIは使わず、`video/make_video.py` で静止画・テロップ・吹き出し・口パク・場面転換を組み立てる。

台本の書き方は `video/README.md`、見本は `video/sample/台本.yaml`。

---

## 使い方

```
/video 台本.yaml            ← 台本から動画を書き出す
/video 台本を作って <テーマ>  ← 投稿テーマから台本を下書きする
```

---

## 台本から動画を書き出すとき

1. `python3 video/make_video.py <台本> --preview` で下見画像を作り、自分で見る
   - 文字が顔や大事な部分にかぶっていないか
   - 文字が画面からはみ出していないか
2. 問題があれば「位置」や改行を直して、もう一度下見する（直すのは1回まで。直らなければそのまま進めて記録する）
3. `python3 video/make_video.py <台本>` で書き出す
4. 書き出した動画と下見画像をユーザーに送る。直した箇所があれば一覧で伝える

台本エラーが出たら、エラー文に従って1度だけ直す。直らなければ、エラー文をそのままユーザーに伝える。

---

## 台本を下書きするとき

- 文体は CLAUDE.md と `skills/style/SKILL.md` に従う。煽らない
- 長さは20〜30秒（5〜7シーン）を目安にする
- 流れの型（参考にした動画の構成）
  1. つまずいている場面を一言で（驚き顔＋大きいテロップ）
  2. キャラのツッコミ（セリフ）
  3. ワイプで切り替えて「まずは〇〇」（「／」で時間差表示）
  4. 具体例を1つ（画像を重ねる）
  5. 次の一歩を一言で＋読者への問いかけ（下のテロップ）
- 1シーンに出す文字は2行まで。強調（【】）は1シーンに1か所
- 絵のファイル名は、ユーザーがまだ絵を持っていなければ `video/sample/絵/` の仮の絵を使い、差し替える場所をメモ欄に書く
