# 状況の分かれ方 20パターン

記事の型の「6. 状況の分かれ方」で使います。
500円を成立させる部分です。ここが100円の記事との違いです。

## 4つの軸

### 軸1：規模で分かれる
| No. | 分かれ方 |
|---|---|
| 1 | 1人でやる場合 / 数人でやる場合 / 部署全体の場合 |
| 2 | 1件だけ / 10件程度 / 100件以上 |
| 3 | 今回だけ / 毎月ある / 毎日ある |
| 4 | 個人で完結 / 社内の承認が要る / 社外が絡む |
| 5 | 金額が小さい / 稟議が必要な額 / 役員決裁の額 |

### 軸2：時期で分かれる
| No. | 分かれ方 |
|---|---|
| 6 | 期限まで余裕がある / 今週中 / 今日中 |
| 7 | 始まる前 / 進行中 / 終わったあと |
| 8 | 年度の始め / 途中 / 年度末 |
| 9 | まだ何も始めていない / 途中で止まっている / やり直し |
| 10 | 初めて / 2回目以降 / 前任から引き継いだ |

### 軸3：立場で分かれる
| No. | 分かれ方 |
|---|---|
| 11 | 自分で決められる / 上司の承認が要る / 自分は実務だけ |
| 12 | 依頼する側 / 依頼される側 |
| 13 | 正社員 / 契約や派遣 / 業務委託 |
| 14 | 専任で担当 / 他の仕事と兼任 |
| 15 | 聞ける人がいる / 誰もいない |

### 軸4：状態で分かれる
| No. | 分かれ方 |
|---|---|
| 16 | 既存のものを直す / ゼロから作る |
| 17 | 前例がある / 前例がない |
| 18 | ツールが使える / 紙とメールだけ |
| 19 | 予算がある / 予算ゼロ |
| 20 | 社内ルールが決まっている / 決まっていない |

## 選び方

テーマごとに、**いちばん手順が変わる軸を1つ**選びます。

| やり方 | 結果 |
|---|---|
| × 4つの軸を全部入れる | 組み合わせが多すぎて、読めない |
| × 分かれ方が2つしかない | 100円の商品になる |
| ◯ 1つの軸で、3つに分ける | 読者が自分のケースを選べる |

## 15番を見落とさない

「聞ける人がいる / 誰もいない」の軸は、ほとんど使われていません。
でも、500円を払う人の多くは後者です。聞ける人がいれば、その人に聞いています。
ここで分けると、刺さり方が変わります。

## 補足：2つしかないパターンを3つにする案（Claudeの追加案・未承認）

12、14〜20番は、元の分かれ方が2つです。このまま使うと「2つで済ませる」禁止に当たるため、3つ目の案を置いておきます。採用するかどうかは判断してください。

| No. | 3つにした案 | 足した部分 |
|---|---|---|
| 12 | 依頼する側 / 依頼される側 / 間に立って取りまとめる側 | 取りまとめる側 |
| 14 | 専任で担当 / 他の仕事と兼任 / 一時的に代理で担当 | 一時的な代理 |
| 15 | 聞ける人がいる / 聞ける人はいるが頼りにくい（忙しい・異動した・社外） / 誰もいない | 頼りにくい |
| 16 | 既存のものを直す / 他から雛形を借りて作る / ゼロから作る | 雛形を借りる |
| 17 | 前例がある / 前例はあるが古くて使えない / 前例がない | 古い前例 |
| 18 | 会社指定のツールがある / 無料ツールなら使ってよい / 紙とメールだけ | 無料ツールならよい |
| 19 | 予算がある / 少額なら申請で出る / 予算ゼロ | 少額なら出る |
| 20 | 社内ルールが決まっている / 決まっているが古い・守られていない / 決まっていない | 形だけのルール |

15番を3つにした案では、真ん中の「聞ける人はいるが頼りにくい」が、最も人数の多い読者になると見ています（推測です。需要は未確認）。
