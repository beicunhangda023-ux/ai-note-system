# フィードバック記録

このファイルは、初稿を修正したパターンを蓄積するファイルです。
/learn コマンドを使うと自動で追記されます。
次回の /note_auto 実行時に、このファイルを読んでから書きます。

---

## 使い方

1. /note_auto で初稿を生成する
2. 初稿を読んで、自分の言葉に直す
3. 修正が終わったら /learn を叩く
4. Claude Codeが差分を読み取り、ここに追記する

---

## 修正記録

（/learn コマンドを実行すると、ここに自動で追記されます）

---

## 手動でよくある修正を追記するには

以下の形式で書き足してください。

```
## 修正記録 #X
修正前：「（AIが書いた文章）」
修正後：「（自分が直した文章）」
理由：（なぜ直したか）
→ ルール追加：（次回から守ってほしいこと）
```

---

## 初期ルール（最初から効かせたいもの）

### ルール1：「まとめると」で締めない
修正前：「まとめると、今回は3つのポイントをお伝えしました」
修正後：（削除または「ここまでで〜が揃いました」のように自然に繋げる）
理由：「まとめると」で締めるのが教材っぽい

### ルール2：「活用」「効率的」「可能」の組み合わせを避ける
修正前：「この方法を活用することで、効率的に作業が可能です」
修正後：「この方法を使うだけで、作業が早く終わります」
理由：AI臭い定番フレーズになりやすい

### ルール3：冒頭を説明から始めない
修正前：「本記事では、〜について説明します」
修正後：（読者の状況・悩みから入る）
理由：教材っぽい入り方は読者が離脱する
