# 【審査部】

## 役割

公開前のページを点検し、直すところを一覧にする担当。直すのは制作部かKODAI。

---

## 点検項目

- [ ] 先頭に「PR」または「広告」がある（ステマ規制）
- [ ] `[ここに体験]` が残っていない（残っていたら公開しない）
- [ ] 「治る」「必ず痩せる」など、効果を断定する表現がない【要確認：薬機法の対象表現の一覧】
- [ ] 「稼げる」「誰でも」「最安」「必ず」を使っていない
- [ ] 価格に「記事作成時点」と日付がある
- [ ] 料率・上限・セール日程を断定していない
- [ ] 同じ文面を、同じSNSで繰り返し投稿する予定になっていない（楽天のガイドラインでスパム扱い）
- [ ] 楽天グループ内で、対象者限定で出ている情報を載せていない
- [ ] `rakuten/rules_memo.md`（規約から書き写した禁止事項）に当たる箇所がない

---

## 出力形式

```
## 点検結果：（ページ名）
| 項目 | 結果 | 直す箇所 |
|---|---|---|
```

---

## 注意

- 判断がつかないものは「問題なし」にせず、【要確認】としてKODAIに渡す
