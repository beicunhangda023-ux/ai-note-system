# 台本から動画を作る仕組み

台本（文字だけのファイル）と絵を用意すると、Threads や X に載せる解説動画を書き出します。動画生成AIは使いません。

できること：

- シーンごとに絵を切り替える（表情違いの絵を順番に出す）
- 口パク（口を閉じた絵と開けた絵を、しゃべっている間だけ交互に出す）
- テロップを時間差で出す（「まずは、」→「誰に、」→「何を届けるか。」）
- 名前つきの吹き出しでセリフを出す
- 赤い矢印のワイプや、フェードでの場面転換
- 絵の上に別の画像（見本・スクショなど）を重ねる
- ナレーションの音声とBGMを入れる

---

## 1. 試しに動かす

```
python3 video/make_video.py video/sample/台本.yaml
```

`workspace/台本.mp4` ができます。サンプルの絵は仮のキャラクターです。

書き出す前に配置だけ確認したいときは `--preview` をつけます。各シーンの静止画を並べた `workspace/台本_下見.png` ができます。

```
python3 video/make_video.py video/sample/台本.yaml --preview
```

### 自分のパソコンで動かすのに必要なもの

| もの | Mac | Windows |
|---|---|---|
| Python 3 | 最初から入っていることが多い。ターミナルで `python3 --version` | python.org からインストール |
| ffmpeg（動画を組み立てる無料ソフト） | `brew install ffmpeg` | `winget install ffmpeg`【要確認】 |
| 画像と台本を読む部品 | `pip3 install pillow pyyaml` | `pip install pillow pyyaml` |

インストールが面倒なら、Claude Code に絵と台本を渡して「この台本で動画にして」と頼めば書き出せます（`skills/video.md`）。

---

## 2. 絵を用意する

参考にした動画のように、**同じ構図で表情だけ違う絵**を数枚用意します。

1. ChatGPT などで基本の1枚を作る
   例：「海辺のカフェのテラスで、茶髪の女の子と白い猫がテーブルに座っている。アニメ調。横長16:9」
2. その絵をアップロードして、表情違いを頼む
   例：「この絵の構図・服・背景はそのままで、表情だけ驚いた顔にしてください」
3. 口パク用に、それぞれの表情の「口を開けた版」も頼む
   例：「この絵とまったく同じで、口だけ少し開けた状態にしてください」
4. 背景や服がずれた絵は作り直す（口パクのときに絵全体がチラつくため）

ファイル名は `ふつう.png` `ふつう_口.png` `驚き.png` のように、見て分かる名前にしておくと台本が書きやすくなります。台本と同じフォルダか、その中の `絵/` フォルダに置きます。

絵は画面いっぱいに広げ、はみ出した部分は上下（または左右）を切り落とします。縦長の動画（設定のサイズを `縦`）にするときは、絵も縦長（9:16）で作ってください。横長の絵のままだと左右が大きく切れて、キャラが画面からはみ出します。

## 3. 台本の書き方

`video/sample/台本.yaml` をコピーして書き換えるのがいちばん早いです。

### 文字の中で使える記号

| 書き方 | 意味 |
|---|---|
| `【作れる】` | 赤（強調色）にする。【】は画面には出ない |
| `まずは、／誰に、／何を` | 「／」（全角スラッシュ）で区切ると、「間」の秒数ごとに順番に出る |
| `"1行目\n2行目"` | 改行。`\n` を使うときは全体を `"` で囲む |

`*` や `[` で始まる文字は台本の書き方として特別な意味を持つので、`"` で囲んでください。

### 設定（台本のいちばん上。省略可）

| 項目 | 書き方の例 | 省略したとき |
|---|---|---|
| サイズ | `横` / `縦` / `正方形` / `[1280, 720]` | 横（1920×1080） |
| FPS | `30` | 30 |
| フォント | `fonts/MPLUSRounded1c-ExtraBold.ttf` | パソコンにある太めの日本語フォント |
| BGM | `bgm.mp3`（動画の長さまでくり返す） | なし |
| BGM音量 | `0.15` | 0.15 |
| 文字色 / 強調色 / 縁色 / 切り替え色 | `"#E8452C"` | 紺 / 赤 / 白 / 赤 |
| 出力 | `workspace/今日の動画.mp4` | workspace/台本名.mp4 |

### シーン

| 項目 | 書き方の例 | 意味 |
|---|---|---|
| 秒 | `3.5` | シーンの長さ。「音声」があれば省略でき、そのときは音声の長さ＋0.4秒 |
| 絵 | `絵/驚き.png` | 背景の絵 |
| 口パク | `絵/驚き_口.png` | 口を開けた版。セリフの間だけ交互に出る |
| ズーム | `true` | シーンの間、ゆっくり寄っていく |
| 切り替え | `ワイプ` / `フェード` / `なし` | 前のシーンからの切り替え方 |
| 音声 | `声/01.mp3` | シーンの頭から流す音声 |
| テロップ / セリフ / 画像 | 下の表 | 画面に出すもの。いくつでも並べられる |
| メモ | 何でも | 自分用のメモ。動画には出ない |

シーンの途中で表情を変えたいときは、「絵」を次のように書きます。

```yaml
    絵:
      - から: 0
        絵: 絵/ふつう.png
        口パク: 絵/ふつう_口.png
      - から: 2.4
        絵: 絵/笑顔.png
```

### テロップ・セリフ・画像に共通の項目

| 項目 | 書き方の例 | 省略したとき |
|---|---|---|
| から | `0.5`（シーンの頭から何秒後に出すか） | 0 |
| まで | `3`（何秒後に消すか） | シーンの終わり |
| 位置 | `左上` `上` `右上` `左` `中央` `右` `左下` `下` `右下` か `[横%, 縦%]` | テロップは中央、セリフは左上 |
| 動き | `ポン` / `フェード` / `なし` | テロップとセリフはポン、画像はフェード |
| 間 | `0.6`（「／」の区切りが出る間隔） | 0.6 |
| 口パク | `true` / `false` | セリフは true、テロップは false |
| 音声 | `声/02.mp3`（出たときに流す） | なし |

`[横%, 縦%]` は、画面の左上を 0、右下を 100 として、そのものの左上の角を置く場所です。

### テロップだけの項目

| 項目 | 書き方の例 | 省略したとき |
|---|---|---|
| 文字 | `見本を【1本】つくる。` | （必須） |
| 大きさ | `特大` `大` `中` `小` | 中 |
| 種類 | `ふつう`（白フチ文字） / `タグ`（紺の箱に白文字。「AI副業」のような見出し） | ふつう |
| 色 | `"#2A6FDB"` | 設定の文字色 |

### セリフだけの項目

| 項目 | 書き方の例 | 省略したとき |
|---|---|---|
| 名前 | `ニャンズ`（吹き出しの左上に出る） | 名前なし |
| 文字 | `えっ、でも／【課金ばっかり】や！` | （必須） |
| 大きさ | `特大` `大` `中` `小` | 小 |
| 色 | `"#4B3A8C"`（吹き出しのフチと名前の箱の色） | 紫 |
| しっぽ | `右下` / `左下` / `なし` | 右下 |

### 画像だけの項目

| 項目 | 書き方の例 | 省略したとき |
|---|---|---|
| ファイル | `絵/見本.png` | （必須） |
| 幅 | `42`（画面の幅の何%にするか） | 50 |
| 枠 | `true` / `false`（白いフチをつけるか） | true |

## 4. うまくいかないとき

| 症状 | 対処 |
|---|---|
| `台本エラー: ○番目のシーンのテロップ2 に知らない項目があります` | 項目名の打ち間違い。エラーに「使える項目」が出るので、その中から選ぶ |
| `台本の書き方に間違いがあります（行と列の番号を見てください）` | 字下げ（行頭のスペース）がずれているか、`*` `[` で始まる文字を `"` で囲んでいない |
| `ファイルが見つかりません` | ファイル名の打ち間違いか、台本からの場所の書き方の違い。台本と同じフォルダが基準 |
| 口パクで絵全体がチラつく | 口を開けた版の絵の背景や服がずれている。ずれていない版を作り直す |
| 文字が顔にかぶる | 「位置」を変えるか、文字の途中に `\n` を入れて改行する。`--preview` で確認すると早い |
| 文字が細い・好みと違う | 設定の「フォント」に好きなフォントファイルを書く（太めの丸ゴシックなど） |
